# Netflix Content Analytics using SQL

## Project Overview

This project analyzes Netflix movies and TV shows using SQL to discover
content trends, distribution, and meaningful insights.

## Objectives

- Analyze Movies and TV Shows
- Identify top content-producing countries
- Analyze popular genres
- Study Netflix content trends over the years
- Analyze content ratings
- Generate meaningful business insights

## Tools & Technologies

- SQL
- Git
- GitHub
- Power BI
